このブログは、Markdown ファイルから静的に生成されています。

## このブログについて

`/posts` フォルダに `.md` ファイルを置くだけで、一覧ページと詳細ページが作られます。

### 記事を追加する手順

1. `/posts` に新しい `.md` ファイルを作る
2. 先頭に title / date / tags を書く
3. GitHub に push する

### コードの例

```js
const message = "Hello, world";
console.log(message);
```

## まとめ

記事の追加は、ファイルを1本足すだけです。
